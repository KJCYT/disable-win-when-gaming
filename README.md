# disable-win-when-gaming
打游戏误触 Win 键跳出开始菜单、画面卡住？这个工具在游戏运行时自动禁用 Win 键，游戏退出后自动恢复。windows, gaming, autohotkey-alternative, keyboard-hook, python, windows-key, win-key, disable-windows-key, gaming-tools, ctypes使用全局键盘钩子实现，不修改注册表、不重写 Scancode Map，进程结束即恢复，不会留下“Win 键永久失效”的残留。内置 49 个常见游戏进程名，并支持按全屏独占窗口自动识别。单文件 Python，仅标准库，无第三方依赖。
